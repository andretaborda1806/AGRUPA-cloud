# AGRUPA Cloud — User Guide

## Purpose

This guide explains how team members should use AGRUPA Cloud.

## Access

Users access the cloud through the web interface.

Current internal address:

```txt id="o832om"
http://10.0.0.2
```

If the service is later configured with a domain, users should use the official domain instead.

## Login

Each user receives:

```txt id="h6w0iq"
username
temporary password
```

After the first login, the user should change the password.

## Changing password

In the Nextcloud web interface:

```txt id="lwm2hr"
User menu → Personal settings → Security → Password
```

## Uploading files

Users can upload files by:

1. opening the Files app;
2. entering the target folder;
3. clicking `+`;
4. selecting `Upload file`.

## Team folders

Shared team folders appear automatically in the Files app.

Examples:

```txt id="q83j67"
Shared Documents
Team Folder
AGRUPA
```

Users with edit permissions can:

```txt id="665gfs"
open files
upload files
create folders
edit documents
delete files
share files, if allowed
```

## Editing Office documents

Supported file types include:

```txt id="t5jl0f"
.docx
.xlsx
.pptx
.odt
.ods
.odp
```

To edit a document:

1. open Nextcloud;
2. go to the shared folder;
3. click the document;
4. the document should open in the browser through Nextcloud Office/Collabora.

If the file downloads instead of opening, contact the administrator.

## Sharing files

To share a file:

1. click the share icon;
2. select the user or group;
3. choose the permissions;
4. send the link or internal share.

## Deleted files

Deleted files may be available in:

```txt id="o0i3z5"
Deleted files
```

Users should contact the administrator if important files disappear.

## Good practices

Users should:

```txt id="bai44g"
use clear file names
avoid duplicate versions
avoid uploading unnecessary large files
organize files by folder
log out on shared computers
use strong passwords
not share credentials
```
